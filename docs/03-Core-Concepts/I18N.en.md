# Internationalization (I18n)

Your app speaks multiple languages thanks to the `I18n` service. Defaults: Spanish (`es`) and English (`en`).

## 1. Translation Files

Texts live in `src/i18n/`.

- `src/i18n/es.json`
- `src/i18n/en.json`

```json
// en.json
{
    "WELCOME": "Welcome, %s",
    "ERROR_LOGIN": "Invalid credentials"
}
```

## 2. Using Translations in BO

From any BO, use `this.t()`.

```typescript
// Simple
return this.error(this.t('ERROR_LOGIN'))

// With parameters
const msg = this.t('WELCOME', 'Pepe') // "Welcome, Pepe"
```

## How does it know the language?

The client sends an `Accept-Language` header or we configure a default (`APP_LANG` in `.env`).
The `I18n` service selects the correct file automatically.

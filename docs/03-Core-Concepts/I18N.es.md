# Internacionalización (I18n)

Tu aplicación habla múltiples idiomas gracias al servicio `I18n`. Por defecto: Español (`es`) e Inglés (`en`).

## 1. Archivos de Traducción

Los textos viven en `src/i18n/`.

- `src/i18n/es.json`
- `src/i18n/en.json`

```json
// es.json
{
    "WELCOME": "Bienvenido, %s",
    "ERROR_LOGIN": "Credenciales inválidas"
}
```

## 2. Usando Traducciones en BO

Desde cualquier BO, usa `this.t()`.

```typescript
// Simple
return this.error(this.t('ERROR_LOGIN'))

// Con parámetros
const msg = this.t('WELCOME', 'Pepe') // "Bienvenido, Pepe"
```

## ¿Cómo sabe el idioma?

El cliente envía un header `Accept-Language` o configuramos un default (`APP_LANG` en `.env`).
El servicio `I18n` selecciona el archivo correcto automáticamente.
